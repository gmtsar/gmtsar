## Honest framing

- **Algorithm-level: py beats C.** Kernel-isolated benchmarks show:
  - xcorr_py 1.61× (FFT batching)
  - resamp_py 1.33× (Numba @njit single-thread vs C inner loops)
  - gmt_surface_py FMG 1.93× (anisotropic single-thread)
- **Cumulative wall: py 1.032× csh.** Limited by NFS page-fault contention
  on stripmap cases (CSK/TSX/ALOS2_Japan). madvise fix expected to flip
  those.
- **Strict single-core throughout.** No `parallel=True` in Numba; all
  thread caps locked at 1 for honest comparison.
